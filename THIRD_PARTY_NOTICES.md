# Sources, versions and licenses

- **Three.js 0.186.1**, MIT. Core, WebGPU, TSL and add-on imports use the same
  locked version. Its full license is distributed in `dist/THREE-LICENSE.txt`.
  [WebGPU renderer](https://threejs.org/manual/pages/webgpurenderer),
  [node-based post-processing](https://threejs.org/manual/pages/webgpu-postprocessing.html),
  [source](https://github.com/mrdoob/three.js).
- **esbuild 0.28.2**, MIT; development/build dependency only.
  [Project](https://github.com/evanw/esbuild).
- **Playwright 1.64.1**, Apache-2.0; development/browser-test dependency only.
  Neither Playwright nor its test browsers are bundled into the game.
  [Project and license](https://github.com/microsoft/playwright).
- **Node.js 24+** is a separately installed runtime; its binary is not distributed
  in this project. Rust is likewise a separate build tool, not a game dependency.
- Vegetation geometry, noise and some textures are generated by code. The
  user-provided `Meshy_AI_Starlight_Voyager_1020235536_texture.glb` model is stored
  as `assets/starlight-voyager.glb`. Stamps derived from user-provided terrain GLB
  files are in `assets/terrain-stamps/`. These assets have third-party/user
  origins; this repository does not grant them MIT or any other new license.

The following works informed algorithmic concepts. This does not claim that their
complete reference implementations are included in this project:

- Barnes, Lehman, Mulla - [Priority-Flood](https://richard.science/sci/2014_depressions.pdf).
- Steven Wittens - [Spheres and cubes](https://acko.net/blog/making-worlds-1-of-spheres-and-cubes/).
- Jerry Tessendorf - [Simulating Ocean Water](https://jtessen.people.clemson.edu/reports/papers_files/coursenotes2004.pdf).
- Sebastien Hillaire - [Atmosphere reference](https://github.com/sebh/UnrealEngineSkyAtmosphere).
- [WebGPU specification](https://www.w3.org/TR/webgpu/).

Implementation scope differences are preserved in
[the original delivery report](docs/history/TESLIM_RAPORU.md).
The v1.3 terrain investigation and its references are preserved in
[ARAZI_V13.md](docs/history/ARAZI_V13.md). Rock textures are generated locally.
Three.Terrain and third-party erosion plug-ins are not included.
